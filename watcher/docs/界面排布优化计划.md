# 界面排布优化计划

> 基于当前截图分析，目标：最大化树视图可视面积，减少操作层级，提升信息密度。

## 1. 当前问题

| 问题 | 影响 |
|------|------|
| Hero 标题区占 ~120px 垂直空间 | 树画布被压缩 |
| 左侧 Control Deck 占 25% 宽度 | 树画布被挤窄，且控件使用频率低（设置一次后很少改动） |
| Session 状态在右上角，Start/Stop 在左侧栏 | 操作与反馈分离 |
| 树上方有 4 行控件（标题行、提示文字、日期/树选择行、Trim Branches 行） | 吃掉 ~160px 垂直空间 |
| View Switcher 独占一行 | 浪费垂直空间 |
| Categories 输入框 + Apply 按钮常驻侧栏 | 低频操作占高频位置 |

## 2. 目标布局

```
┌─────────────────────────────────────────────────────────┐
│ 🌳 Watcher  [Tree] [Cards] [Logs]    ● Running  [⚙]  [☀] │  ← 顶栏 48px
├─────────────────────────────────────────────────────────┤
│ 2026-02-11 ▾ │ Tree 00:41 ▾ │ 写代码 研究 娱乐 │ - + │  ← 工具栏 40px
├─────────────────────────────────────────────────────────┤
│                                                         │
│                                                         │
│                    树 Canvas                             │  ← 占满剩余高度
│                  （全宽，无侧栏）                          │
│                                                         │
│                                                         │
├─────────────────────────────────────────────────────────┤
│ [Start] [Manual] [Stop]                    09:00-16:32  │  ← 底栏 44px
└─────────────────────────────────────────────────────────┘

⚙ 点击弹出设置面板（时间窗口、频率、显示器、分类）
```

## 3. 改动清单

### 3.1 顶栏（Top Bar）— 替代 Hero + View Switcher + Status Box

将三个独立区域合并为一个 48px 高的顶栏：

```
左侧：Logo 文字 "Watcher"（小号 Fraunces）
中间：View Switcher 三个 tab（Tree / Cards / Logs）
右侧：状态 badge（Running/Stopped）+ 设置齿轮按钮 + 主题切换
```

改动文件：
- `index.html`：删除 `.hero` 区域，新建 `.top-bar`
- `style.css`：新增 `.top-bar` 样式，`position: sticky; top: 0; z-index: 10`
- `app.js`：View Switcher 挂载点改为顶栏内

### 3.2 工具栏（Toolbar）— 替代 tree-head + tree-filter-bar + branch-row

将树视图上方的 4 行控件压缩为 1 行：

```
[日期 ▾] [树 ▾] [New] [Del]  │  写代码 研究 娱乐  │  [-] [+] [Reset]
```

改动文件：
- `index.html`：合并 `.tree-head`、`.tree-filter-bar`、`.branch-row` 为 `.tree-toolbar`
- `style.css`：`.tree-toolbar` 用 `display: flex; align-items: center; gap`，单行排列
- 删除 `treeHint` 提示文字（改为 tooltip 或首次使用引导）

### 3.3 全宽画布 — 删除侧栏

移除左侧 Control Deck 常驻侧栏，树画布占满整个宽度：

```css
/* 之前 */
.workspace { grid-template-columns: minmax(270px, 336px) minmax(0, 1fr); }

/* 之后 */
.workspace { grid-template-columns: 1fr; }
```

改动文件：
- `index.html`：将 `.control-card` 从 `.workspace` 中移出，改为弹出面板
- `style.css`：`.workspace` 改为单列，画布高度改为 `calc(100dvh - 顶栏 - 工具栏 - 底栏)`

### 3.4 底栏（Bottom Bar）— 操作按钮 + 时间范围

将 Start/Stop/Manual 按钮从侧栏移到底部固定栏：

```
左侧：[▶ Start] [📸 Manual] [■ Stop]
右侧：时间范围标签 09:00 - 16:32
```

改动文件：
- `index.html`：新建 `.bottom-bar`
- `style.css`：`position: sticky; bottom: 0`，半透明背景 + backdrop-filter
- `app.js`：按钮引用不变，只是 DOM 位置移动

### 3.5 设置面板（Settings Panel）— 替代 Control Deck

点击顶栏齿轮图标，弹出右侧滑入面板或模态框：

```
┌──────────────────┐
│ Settings      ✕  │
│                  │
│ 时间窗口         │
│ [09:00] - [18:00]│
│                  │
│ 观察频率         │
│ [30] 秒          │
│                  │
│ 显示器           │
│ [Display 2 ▾]    │
│ [预览]           │
│                  │
│ 分类             │
│ [写代码,研究,娱乐]│
│ [Apply]          │
└──────────────────┘
```

改动文件：
- `index.html`：`.control-card` 改为 `.settings-drawer`，加 overlay
- `style.css`：抽屉样式，`position: fixed; right: 0; top: 0; height: 100dvh; width: 320px; transform: translateX(100%); transition: transform 0.3s`
- `app.js`：新增 `toggleSettings()` 函数

### 3.6 画布高度最大化

优化后的垂直空间分配：

```
之前：
  Hero:           ~120px
  View Switcher:   ~50px
  Workspace gap:   ~12px
  Tree head:       ~48px
  Tree hint:       ~24px
  Filter bar:      ~52px
  Branch row:      ~36px
  Canvas:          剩余（约 100dvh - 342px）
  ─────────────────
  Canvas 可用高度 ≈ 58% viewport

之后：
  Top bar:          48px
  Toolbar:          40px
  Canvas:           剩余
  Bottom bar:       44px
  ─────────────────
  Canvas 可用高度 ≈ 100dvh - 132px ≈ 87% viewport
```

画布面积提升约 **50%**。

## 4. 实施顺序

```
Phase 1（结构重组）：
  1. 新建顶栏，迁移 logo + view switcher + status
  2. 删除 hero 区域
  3. 合并树控件为单行工具栏
  4. 移除侧栏，画布全宽

Phase 2（交互优化）：
  5. 新建底栏，迁移操作按钮
  6. 新建设置抽屉面板
  7. 齿轮按钮开关逻辑

Phase 3（细节打磨）：
  8. 响应式适配（移动端工具栏折叠）
  9. 动画过渡（抽屉滑入、工具栏收起）
  10. 键盘快捷键（S 开始、P 暂停、G 设置）
```

## 5. 不改动的部分

- Canvas 渲染逻辑（app.js 中的 draw* 函数）
- Cards / Logs 视图内部布局
- 后端 API
- 数据流和状态管理
