## 1. 背景

当前日报总结面板嵌在页面底部，视觉上与 Cards 视图高度重复，缺乏独立感。
用户期望：

## 2. 核心设计

### 2.1 独立视图
- ViewSwitcher 新增第 5 个 tab：`📊 日报`
- 切换到日报视图时显示独立的全屏区域
- 移除旧的底部日报面板

### 2.2 流式生成体验
- 后端新增 SSE（Server-Sent Events）端点 `/api/daily-summary/stream`

- LLM 生成阶段使用 OpenAI streaming（`stream: true`），逐 token 推送
- 前端实时渲染：打字机效果显示 AI 总结文字

## 3. Agent 分工

### 3.1 Agent A — 后端（SSE 流式端点）

#### 任务清单

**3.1.1 SSE 流式端点（`app/web.py` 修改）**
- 新增 `GET /api/daily-summary/stream?date=YYYY-MM-DD&force=false`
- 使用 Flask `Response` + `text/event-stream` content type
- 生成器函数逐步 yield SSE 事件：
  ```python
  def generate_summary_stream(date_str, force):
      # Phase 1
      yield f"event: phase\ndata: {json.dumps({'phase': 'parsing', 'message': '正在解析活动记录...'})}\n\n"
      entries = parse_daily_report(...)

      # Phase 2
      yield f"event: phase\ndata: {json.dumps({'phase': 'aggregating', 'message': '正在聚合统计数据...'})}\n\n"
      stats = aggregate_stats(entries)
      segments = build_timeline_segments(entries)

      # Phase 3: LLM streaming
      yield f"event: phase\ndata: {json.dumps({'phase': 'generating', 'message': '正在生成 AI 总结...'})}\n\n"
      # 逐 token 推送
      for token in stream_llm_summary(...):
          yield f"event: token\ndata: {json.dumps({'text': token})}\n\n"

      # Phase 4: 完成
      yield f"event: done\ndata: {json.dumps(full_payload)}\n\n"
  ```

**3.1.2 LLM 流式调用（`watcher/daily_summary.py` 修改）**
- 新增 `stream_llm_summary(entries, stats, config)` 生成器函数
- 使用 `requests.post(..., stream=True)` + OpenAI streaming 格式
- 逐行解析 `data: {...}` SSE 响应，yield 每个 token
- 降级：如果 streaming 不可用，一次性返回完整结果

**3.1.3 Service 层（`app/service.py` 修改）**
- 新增 `daily_summary_stream(date_str, force)` 生成器方法
- 编排：解析 → 聚合 → LLM 流式 → 缓存保存

**3.1.4 缓存检查优化**
- SSE 端点先检查缓存，有缓存时直接推送 `event: cached` + 完整数据（跳过生成）
- `force=true` 时跳过缓存

**3.1.5 测试**
- `tests/test_daily_summary.py` 新增流式生成器测试
- 测试 SSE 事件格式正确性

**3.2.3 SSE 客户端 + 动画引擎（`app.js` 修改）**

核心函数：
- `streamDailySummary(dateText, force)` — 建立 EventSource 连接
  ```javascript
  const es = new EventSource(`/api/daily-summary/stream?date=${date}&force=${force}`);
  es.addEventListener("phase", (e) => { showPhase(JSON.parse(e.data)); });
  es.addEventListener("token", (e) => { appendToken(JSON.parse(e.data).text); });
  es.addEventListener("cached", (e) => { renderCachedResult(JSON.parse(e.data)); });
  es.addEventListener("done", (e) => { finalizeSummary(JSON.parse(e.data)); es.close(); });
  es.addEventListener("error", (e) => { handleStreamError(e); es.close(); });
  ```

- `showPhase(data)` — 显示阶段指示器（脉冲点动画）
- `appendToken(text)` — 打字机效果追加文字到 AI 总结区
- `finalizeSummary(payload)` — 流结束后：
  - 隐藏光标
  - 逐条淡入亮点（每条间隔 200ms）
  - 逐条滑入时间线段（每条间隔 150ms）
- `renderCachedResult(payload)` — 缓存命中时直接渲染（无动画或快速动画）

视图切换集成：
- `setActiveView("summary")` 时显示 `#summaryViewSection`
- 自动检查缓存并渲染
- 移除旧的 `refreshDailySummaryForDate` 等函数

## 4. 接口约定

### 4.1 SSE 端点

`GET /api/daily-summary/stream?date=YYYY-MM-DD&force=false`

Content-Type: `text/event-stream`

#### 事件类型

| event | data 格式 | 说明 |
|-------|-----------|------|
| `phase` | `{"phase":"parsing","message":"正在解析..."}` | 阶段切换 |
| `token` | `{"text":"今天"}` | LLM 输出 token |
| `highlights` | `{"highlights":["...",""]}` | 亮点数据 |
| `segments` | `{"timeline_segments":[...]}` | 时间线数据 |
| `cached` | `{完整 payload}` | 缓存命中，直接返回 |
| `done` | `{完整 payload}` | 生成完成 |
| `error` | `{"message":"..."}` | 错误 |

### 4.2 保留原有 API
- `GET /api/daily-summary?date=...` — 仍可用（非流式，读缓存）
- `POST /api/daily-summary/generate` — 仍可用（非流式，生成）

## 6. 注意事项

1. **SSE 兼容性**：EventSource 原生支持所有现代浏览器，无需 polyfill
2. **连接管理**：生成完成或切换视图时必须 `es.close()`，避免连接泄漏
3. **降级方案**：如果 LLM 不支持 streaming，后端一次性返回结果，前端用打字机效果模拟
4. **缓存策略**：流式生成完成后保存缓存；下次打开直接渲染缓存（快速动画或无动画）
5. **成本控制**：仍然只在用户主动点击"生成"时触发 LLM 调用
