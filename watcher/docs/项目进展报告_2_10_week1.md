## 一、项目概述

Watcher 是一个智能工作日志系统，通过截图 + VL 分析自动记录和分类用户活动，并以"成长树"的形式可视化展示时间分配。项目采用 Flask 后端 + Canvas 前端的技术架构。

## 二、本周完成的工作

### 2.1 核心 Bug 修复

#### 问题：2026-02-08 日期树视图缩放异常
- **现象**: 2月8日的树视图缩放范围受限，无法正常缩放，而其他日期正常
- **根因**: 时间范围计算仅基于条目数据范围（10:19-13:35，共196分钟），未考虑配置的工作时间窗口
- **影响**: 用户体验不一致，短时间范围的日期缩放功能受限
- **解决方案**:
  - 修改 `app/service.py` 的 `tree_data` 方法（lines 692-704）
  - 使用数据范围与配置工作窗口（09:00-18:00）的并集
  - 确保最小时间范围为 540 分钟，保证缩放行为一致性
- **状态**: ✅ 已完成，需重启应用生效

**代码变更**:
```python
# 修改前：仅使用数据范围
start_minute = max(min(row["minute"] for row in selected_entries) - 20, 0)
end_minute = min(max(row["minute"] for row in selected_entries) + 20, 1439)

# 修改后：使用数据范围与工作窗口的并集
cfg_start = config.start_time.hour * 60 + config.start_time.minute
cfg_end = config.end_time.hour * 60 + config.end_time.minute
if selected_entries:
    data_start = min(row["minute"] for row in selected_entries) - 20
    data_end = max(row["minute"] for row in selected_entries) + 20
    start_minute = max(min(data_start, cfg_start), 0)
    end_minute = min(max(data_end, cfg_end), 1439)
```
