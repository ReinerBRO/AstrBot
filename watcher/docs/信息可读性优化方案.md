# 信息可读性优化 - Agent 分工方案

> 创建日期：2026-02-11
> 状态：待实施

## 1. 问题背景

树视图和卡片视图的信息展示效率低：
- 树视图：必须逐个 hover 才能获取信息，节点无差异，时间感知弱
- 卡片视图：所有卡片样式一致，技术字段干扰阅读，缺少时间分组

**目标**：让用户扫一眼就能获取关键信息，不需要逐个点击。

---

## 2. Agent 分工总览

| 维度 | Agent A（树视图） | Agent B（卡片视图） |
|------|------------------|-------------------|
| 范围 | Canvas 渲染优化 | HTML/CSS/JS 组件优化 |
| 文件 | `app.js`（Canvas 绑定部分） | `Card.js`, `CardView.js`, `style.css` |
| 依赖 | 无外部依赖 | 无外部依赖 |
| 数据 | 使用现有 `/api/tree` 数据 | 使用现有 `/api/cards` 数据 |

---

## 3. Agent A - 树视图优化

### 3.1 职责范围

修改文件：`app/web_static/app.js`（Canvas 渲染相关函数）

不修改：`index.html`、`style.css`、后端代码

### 3.2 任务清单

#### T-A1：时间参考线（P0）

在 `drawTimeScale()` 函数中增加水平参考线：

```
当前：右侧 4 个时间标签，中间空白
目标：
  - 每小时一条淡色水平虚线（alpha 0.12）
  - 每小时在左侧显示时间标签（如 "10:00"）
  - 当前时间用高亮虚线标注
```

修改位置：`drawTimeScale(ctx, width, height, pad)` 函数

参考实现：
```javascript
// 在现有 drawTimeScale 中添加
const hourStep = 60; // 每60分钟
for (let m = Math.ceil(start / hourStep) * hourStep; m <= end; m += hourStep) {
  const ratio = (m - start) / total;
  const y = pad + ratio * (height - pad * 2);
  // 淡色水平线
  ctx.strokeStyle = isLight ? "rgba(0,0,0,0.08)" : "rgba(255,255,255,0.08)";
  ctx.setLineDash([4, 4]);
  ctx.beginPath();
  ctx.moveTo(pad, y);
  ctx.lineTo(width - pad, y);
  ctx.stroke();
  ctx.setLineDash([]);
  // 左侧时间标签
  ctx.textAlign = "left";
  ctx.fillText(formatHHMM(m), pad + 4, y);
}
```

#### T-A2：果实大小差异化（P1）

在 `buildFruitLayout()` 中根据数据调整果实半径：

```
当前：所有果实 r = 11
目标：r = clamp(8 + log2(click_count + 1) * 3, 8, 20)
```

需要从 entry 数据中提取 click_count（如果有 event_data）。如果没有 event_data，保持默认 r=11。

修改位置：`buildFruitLayout()` 函数，`output.push({ ... r: 11 })` 处

#### T-A3：果实旁标签（P1）

在 `renderTreeFrame()` 的果实绘制循环后，为每个果实绘制简短标签：

```
目标：果实右侧显示 "14:30" 和分类名（小字，alpha 0.7）
规则：
  - 左侧果实（lane < 0）：标签在果实左侧
  - 右侧果实（lane >= 0）：标签在果实右侧
  - 字体：9px IBM Plex Mono
  - 只显示时间，不显示摘要（避免拥挤）
  - 果实密集时（间距 < 25px）跳过标签
```

修改位置：`renderTreeFrame()` 中绘制果实的循环之后

#### T-A4：Tooltip 富文本（P1）

将 tooltip 从纯文本改为 HTML 结构化内容：

```
当前：tooltip.textContent = text
目标：tooltip.innerHTML = 结构化 HTML
```

Tooltip 内容结构：
```html
<div class="tip-head">
  <span class="tip-time">14:30</span>
  <span class="tip-cat" style="background:${color}">写代码</span>
</div>
<div class="tip-summary">实现事件融合系统</div>
<div class="tip-meta">12次点击 · VSCode · 8min</div>
```

修改位置：
- `showTooltip()` 函数：改用 innerHTML
- `renderTreeFrame()` 中构建 tooltip 文本的地方

需要在 `style.css` 中添加 tooltip 子元素样式（提供给 Agent B 或自行添加）。

### 3.3 交付物

1. 修改后的 `app/web_static/app.js`
2. 如有新增 CSS（tooltip 样式），写在 `app.js` 中用 JS 注入，或单独列出交给 Agent B
3. 测试截图：修改前后对比

### 3.4 约束

- 不能破坏现有的缩放、拖拽、键盘导航功能
- 不能影响动画性能（标签绘制要轻量）
- 保持 dark/light 主题兼容
- 果实密集时自动跳过标签，避免文字重叠

## 4. Agent B - 卡片视图优化

### 4.1 职责范围

修改文件：
- `app/web_static/Card.js`（卡片组件）
- `app/web_static/CardView.js`（卡片视图主组件）
- `app/web_static/StatsPanel.js`（统计面板）
- `app/web_static/style.css`（样式）

不修改：`app.js`（Canvas 部分）、后端代码

### 4.2 任务清单

#### T-B1：卡片左侧分类色带（P0）

最简单最有效的改动，1 行 CSS：

```css
.log-card-item {
  border-left: 4px solid var(--category-color);
}
```

分类颜色映射（使用现有 CSS 变量）：
- 写代码 → `var(--work)` (#7bb0ff)
- 研究 → `var(--research)` (#79d9b8)
- 娱乐 → `var(--fun)` (#f1bb63)

在 `Card.js` 的 `render()` 中，根据 category 设置 `--category-color` CSS 变量。

#### T-B2：卡片紧凑模式（P0）

重构卡片布局，默认隐藏技术字段：

```
紧凑模式（默认）：
┌─ 蓝 ─┬──────────────────────────────────┐
│      │ 14:30  写代码           VSCode 8m │
│      │ 实现事件融合系统，完成加权融合...  │
│      └──────────────────────────────────┘

展开模式（点击卡片展开）：
┌─ 蓝 ─┬──────────────────────────────────┐
│      │ 14:30  写代码           VSCode 8m │
│      │ ────────────────────────────────  │
│      │ 实现事件融合系统，完成 VL 和事件  │
│      │ 信号的加权融合引擎开发。          │
│      │                                    │
│      │ 12次点击 · 置信度 0.86 · VL+Event │
│      │ [复制] [编辑] [删除] [查看树]     │
│      └──────────────────────────────────┘
```

修改 `Card.js`：
- 默认 `collapsed = true`
- 紧凑模式：只显示第一行（时间+分类+应用+时长）和摘要（max 2 行，overflow ellipsis）
- 隐藏：ID、source、confidence、操作按钮
- 点击卡片切换展开/折叠

修改 `style.css`：
```css
.log-card-summary.collapsed {
  display: -webkit-box;
  -webkit-line-clamp: 2;
  -webkit-box-orient: vertical;
  overflow: hidden;
}
```

#### T-B3：时间分组（P0）

在 `CardView.js` 的渲染逻辑中，按时间段分组：

```
分组规则：
  - 上午 (09:00 - 12:00)
  - 下午 (12:00 - 18:00)
  - 晚上 (18:00 - 24:00)

分组标题样式：
── 上午 (09:00-12:00) ── 12条 · 主要：写代码 ──
```

修改 `CardView.js`：
- 在 `renderCards()` 中，遍历卡片时检测时间段变化
- 插入分组标题 DOM 元素
- 分组标题显示：时间段名称、条目数、主要分类

修改 `style.css`：
```css
.cards-time-group {
  display: flex;
  align-items: center;
  gap: 0.5rem;
  padding: 0.5rem 0;
  color: var(--muted);
  font: 600 0.75rem "IBM Plex Mono", monospace;
}
.cards-time-group::before,
.cards-time-group::after {
  content: "";
  flex: 1;
  border-top: 1px solid var(--panel-line);
}
```

#### T-B4：卡片时间线（P1）

在卡片列表左侧添加垂直时间线：

```
修改 CardView.js：
  - 卡片列表改为单列布局（时间线模式下）
  - 每张卡片左侧显示时间点和连接线
  - 相邻卡片之间显示间隔时长

样式：
  - 时间点：8px 圆点，分类颜色
  - 连接线：1px 实线（短间隔）或虚线（长间隔 >30min）
  - 间隔标签：小字显示 "15min"、"1h 20min" 等
```

#### T-B5：统计面板优化（P1）

修改 `StatsPanel.js`，将数字统计改为可视化条形图：

```
当前：纯数字 "写代码: 18, 研究: 15, 娱乐: 9"
目标：
  ████████████░░░░  写代码 18条 (43%)
  ████████░░░░░░░░  研究   15条 (36%)
  █████░░░░░░░░░░░  娱乐    9条 (21%)

  活跃 6.5h · 平均间隔 9.3min · 共42条
```

用 CSS 实现条形图（div + width 百分比），不需要 Canvas。

### 4.3 交付物

1. 修改后的 `Card.js`、`CardView.js`、`StatsPanel.js`
2. 修改后的 `style.css`（新增样式）
3. 测试截图：修改前后对比

### 4.4 约束

- 保持 dark/light 主题兼容
- 保持现有的筛选、搜索、分页功能不受影响
- 保持 Fallback 机制（`/api/cards` 不可用时降级到 `/api/tree`）
- 卡片展开/折叠要有平滑过渡动画
- 移动端单列布局不受影响

## 5. 共享约定

### 5.1 颜色变量

两个 Agent 统一使用现有 CSS 变量：
```css
--work: #7bb0ff;      /* 写代码 */
--research: #79d9b8;  /* 研究 */
--fun: #f1bb63;       /* 娱乐 */
--study: #be9dff;     /* 学习（备用） */
--muted: ...;         /* 次要文字 */
--accent: ...;        /* 强调色 */
```

### 5.2 字体

```css
标题/标签: "IBM Plex Mono", monospace
正文/摘要: "Plus Jakarta Sans", sans-serif
```

### 5.3 Tooltip 样式（Agent A 提供结构，Agent B 写 CSS）

Agent A 在 tooltip 中输出 HTML 结构：
```html
<div class="tip-head">...</div>
<div class="tip-summary">...</div>
<div class="tip-meta">...</div>
```

Agent B 在 `style.css` 中添加对应样式：
```css
.tip-head { display: flex; align-items: center; gap: 0.5rem; }
.tip-time { font: 600 0.85rem "IBM Plex Mono"; }
.tip-cat { padding: 2px 8px; border-radius: 4px; font-size: 0.7rem; }
.tip-summary { margin-top: 0.4rem; font-size: 0.82rem; line-height: 1.4; }
.tip-meta { margin-top: 0.3rem; font-size: 0.7rem; color: var(--muted); }
```

## 7. 验收标准

### Agent A
- [ ] 时间参考线：每小时可见水平线和标签
- [ ] 果实大小：有 event_data 的果实明显大于无数据的
- [ ] 果实标签：不 hover 即可看到时间，文字不重叠
- [ ] Tooltip：显示结构化信息（时间、分类、摘要、元数据）
- [ ] 不破坏缩放/拖拽/动画

### Agent B
- [ ] 分类色带：每张卡片左侧有对应颜色的色带
- [ ] 紧凑模式：默认只显示核心信息，点击展开详情
- [ ] 时间分组：卡片按上午/下午/晚上分组，有分组标题
- [ ] 时间线：卡片之间有连接线和间隔时长
- [ ] 统计面板：分类分布用条形图展示
- [ ] dark/light 主题兼容
