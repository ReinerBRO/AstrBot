## 1. 功能概述

### 1.1 目标
在现有树视图的基础上，新增一个卡片式的日志视图选项，让用户可以在两种视图之间自由切换。树视图作为默认视图，卡片视图作为可选的详细查看模式。

### 1.2 核心价值
- **视图切换**：用户可在树视图（默认）和卡片视图之间一键切换
- **可读性**：卡片布局比树视图更适合阅读详细内容
- **可搜索**：支持全文搜索，快速定位特定活动
- **可筛选**：按日期、分类、树等维度筛选
- **可导出**：支持导出为 Markdown、JSON 等格式
- **统计分析**：展示时间分布、分类占比等统计信息

### 1.3 视图对比

| 特性 | 树视图（Tree View）| 卡片视图（Card View）|
|------|-------------------|---------------------|
| **默认状态** | ✅ 默认视图 | 可选视图 |
| **适用场景** | 宏观把握时间线 | 详细回顾和搜索 |
| **可视化** | 树形时间轴 | 卡片列表 |
| **信息密度** | 中等（概览） | 高（详细） |
| **交互方式** | 缩放、拖拽、hover | 筛选、搜索、编辑 |
| **数据展示** | 时间分布、分支 | 完整内容、元数据 |
| **最佳用途** | 快速浏览一天的活动 | 查找特定记录、导出报告 |

### 1.4 与现有功能的关系
- **树视图**（现有，默认）：时间线可视化，适合宏观把握
- **卡片视图**（新增，可选）：详细内容展示，适合回顾和搜索
- **日志视图**（现有）：原始日志，适合调试
- **视图切换器**（新增）：在树视图和卡片视图之间切换

## 3. 数据结构

### 3.1 API 设计

#### 新增 API：`GET /api/cards`

**请求参数**：
```json
{
  "date": "2026-02-07",           // 可选，默认今天
  "date_from": "2026-02-01",      // 可选，日期范围起始
  "date_to": "2026-02-07",        // 可选，日期范围结束
  "categories": ["写代码", "研究"], // 可选，分类筛选
  "tree_ids": ["tree-123"],       // 可选，树筛选
  "search": "LLM",                // 可选，搜索关键词
  "page": 1,                      // 可选，页码（默认 1）
  "page_size": 50,                // 可选，每页数量（默认 50）
  "sort": "time_desc"             // 可选，排序方式
```

### 3.2 前端数据模型

```typescript
interface Card {
  id: string;
  time: string;
  date: string;
  category: string;
  summary: string;
  tree_id: string | null;
  tree_name: string | null;
  source: 'vl' | 'event' | 'vl+event' | 'fusion';
  confidence: number;
  vl_category: string | null;
  event_category: string | null;
  event_data: {
    click_count: number;
    top_app: string;
    active_seconds: number;
  } | null;
}

interface CardFilters {
  date?: string;
  date_from?: string;
  date_to?: string;
  categories?: string[];
  tree_ids?: string[];
  search?: string;
  page?: number;
  page_size?: number;
  sort?: 'time_asc' | 'time_desc';
}

interface CardStats {
  total_count: number;
  category_counts: Record<string, number>;
  total_active_seconds: number;
  avg_interval_seconds: number;
  date_range: {
    start: string;
    end: string;
  };
}
```

### 5.1 核心功能演示

用户打开卡片视图，看到今天的所有活动记录，以卡片形式展示：

## 7. 风险与挑战

### 7.1 性能风险
- **问题**：大数据量（1000+ 条记录）可能导致加载缓慢
- **缓解**：
  - 实现分页或虚拟滚动
  - 后端缓存查询结果
  - 前端使用 Web Worker 处理搜索

### 7.2 数据一致性
- **问题**：编辑/删除操作可能导致报告文件和树元数据不一致
- **缓解**：
  - 实现事务性更新
  - 添加数据验证
  - 定期一致性检查

### 7.3 用户体验
- **问题**：筛选和搜索组合可能导致复杂的 UI 状态
- **缓解**：
  - 清晰的状态指示
  - "重置筛选"按钮
  - URL 参数同步，支持分享链接
