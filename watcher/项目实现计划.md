# 日常工作助手（Watcher）项目实现计划

> 更新日期：2026-02-11（Week 2: Canvas 缩放修复 + 多显示器支持）

## 1. 目标与约束
- 目标：在用户设定时间窗内监视屏幕活动，输出可回看、可筛选的日内成长树记录。
- 约束：通过后端 API 调用 VL/分类模型；本地仅做采集、差异、调度与落盘。
- 成本控制：必须依赖“截图差异 + 最小发送间隔 + 空闲兜底发送”避免高频传图。
- 工程原则：前后端分离、模块化、可扩展、Simple is better。

## 2. 当前实现快照（已落地）
### 2.1 架构与启动
- 已完成分层：
  - `watcher/`：截图采集、aHash 差异、模型调用、调度循环、报告/日志写入。
  - `app/`：Flask API、服务编排、Web 前端（`app/web_static`）。
- 一行启动：`python run.py`（加载 `.env`，启动 `127.0.0.1:8000`）。

### 2.2 监控链路与模型策略
- 截图：优先 `mss`，失败回退 `PIL.ImageGrab`。
- 节流与触发策略（已生效）：
  - `WATCH_INTERVAL_S`
  - `MIN_SEND_INTERVAL_S`
  - `MAX_IDLE_SEND_INTERVAL_S`
  - `HASH_DIFF_THRESHOLD`（aHash + Hamming）
- **事件源与融合（新增）**：
  - 鼠标点击监听（`pynput`）+ 窗口信息采集（应用名、窗口标题）
  - 事件缓冲与聚合（5 分钟滑动窗口）：点击数、应用切换、活跃时长、top_app、关键词
  - 事件触发器：点击 ≥ 6 次或有应用切换时触发分析
  - 事件分类器：规则匹配（关键词）+ LLM 深度分析（混合模式）
  - 融合引擎：VL (0.7) + Event (0.3) 加权融合，智能冲突解决
  - 事件日志：JSONL 格式记录点击事件（`logs/click-events-{date}.jsonl`）
- 模型与分类：
  - VL 调用模式：`VL_API_MODE=auto|openai|simple`
  - 分类可走 `CLASSIFY_API_URL`，失败回退关键词分类
  - 已支持模型分路：`VL_MODEL`、`EVENT_SUMMARY_MODEL`、`FUSION_SUMMARY_MODEL`
  - **LLM 事件分类（新增）**：可选启用 LLM 对事件数据进行深度分析

### 2.3 数据与多树
- 报告：`reports/YYYY-MM-DD.md`，记录格式 `- HH:MM [分类] {tree:id} 摘要`。
- 元数据：`reports/YYYY-MM-DD.trees.json`（含 `deleted` 标记）。
- 多树能力：已支持按日创建/删除树、按树切换查看、删除时同步清理对应报告行。

### 2.4 Web 前端能力
- 控制区：开始/停止、手动记录、频率与分类配置。
- 树交互：缩放、拖拽、时间轴、tooltip、键盘导航、分支 trim。
- 历史日期：
  - 下拉支持前后日期候选；
  - 有数据日期可选；
  - “今天/未来无数据日期”可选；
  - “过去无数据日期”默认禁用（当前策略）。
- 近期稳定性修补（已合入）：
  - 本地时区“今天”判定修复（避免 UTC 偏移）。
  - 无树场景覆盖层与画布模式切换。
  - 树请求序号防抖（防止旧请求覆盖新日期）。
  - 无树切换时清空旧渲染状态，减少“旧树残留”风险。

**完成日期**：2026-02-11

   - 鼠标点击监听（`watcher/event_source/click_listener.py`）

   - 触发检测器：基于点击和切换的智能触发（`watcher/trigger.py`）

## 7. 配置参数（新增）

### 7.1 事件源配置
```bash
ENABLE_EVENT_SOURCE=true              # 启用事件源（默认 true）
EVENT_PRIVACY_MASK=false              # 隐私模式（隐藏窗口标题）
EVENT_BUFFER_WINDOW_S=300             # 事件缓冲窗口（秒）
EVENT_TRIGGER_MIN_CLICKS=6            # 触发最小点击数
EVENT_SWITCH_TRIGGER=true             # 应用切换触发
EVENT_LOG_DIR=logs                    # 事件日志目录
```

### 7.2 融合引擎配置
```bash
FUSION_VL_WEIGHT=0.7                  # VL 权重
FUSION_EVENT_WEIGHT=0.3               # 事件权重
FUSION_CONFIDENCE_THRESHOLD=0.5       # 置信度阈值
```

### 7.3 LLM 事件分类配置
```bash
USE_LLM_EVENT_CLASSIFIER=false        # 启用 LLM 分类器（默认 false）
LLM_EVENT_MODEL=gpt-4o-mini           # LLM 模型
LLM_EVENT_THRESHOLD=0.6               # 规则置信度阈值
LLM_EVENT_ALWAYS=false                # 总是使用 LLM
LLM_EVENT_TIMEOUT_S=10.0              # API 超时
```

### 7.4 多显示器配置
```bash
MONITOR_INDEX=1                       # 显示器索引（默认 1）
```
