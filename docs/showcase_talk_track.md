## Branch

`showcase/v2-memory-growth`

## Version Position

- Version theme: Memory Growth
- Progress share: 18.75%
- Baseline for comparison: V1

## Whole-Group Upgrade Line

`Compared with V1, V2 now remembers past sessions and exposes memory as a visible system capability.`

## What Must Be Obvious On Screen

- a dedicated memory page exists
- the memory timeline and semantic summary are visible
- recalled memory tags appear in replies
- memory items can be edited, hidden, or deleted

## Demo Flow

1. Open the Memory page and point to the timeline plus semantic summary.
2. Start a fresh session.
3. Ask what the system remembers about the user's project preferences.
4. Show recalled memory tags in the response.
5. Edit or delete one memory item to prove memory is inspectable and controllable.

## Difference From Previous Version

- V1 had profile-based personalization but no visible cross-session memory.
- V2 upgrades the shell into a memory-aware system.
- The proof is that the system can recall past goals and expose them in a structured UI.
