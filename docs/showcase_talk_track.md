## Version Position

- Version theme: Action Loop
- Progress share: 18.75%

## Whole-Group Upgrade Line

`Compared with V3, V4 now turns recommendations and intentions into visible executable workflows.`

## What Must Be Obvious On Screen

- a workflow studio is visible
- execution trace and replay panels are visible
- recommendation cards can turn into action cards
- the system can show task decomposition and execution progress

## Demo Flow

1. Open Workflow Studio and point to execution trace and replay.
2. Pick a recommendation or user intent and convert it into an action card.
3. Show task decomposition into several concrete steps.
4. Execute the flow and point to the trace panel.
5. Replay one step or retry it to prove the system is action-capable.

## Difference From Previous Version

- V3 could guide the user but could not visibly execute the suggested work.
- V4 closes the gap between advice and execution.
- The proof is a visible workflow studio, execution trace, and replayable task flow.
