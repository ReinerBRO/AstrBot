# V1 Showcase Talk Track

## Branch

`showcase/v1-integrated-poc`

## Version Position

- Version theme: Integrated PoC
- Progress share: 25%
- Baseline for comparison: original Persbot base system

## Whole-Group Upgrade Line

`Compared with the original base system, V1 now gives us a unified Personalized AI Agent product shell.`

## What Must Be Obvious On Screen

- Persbot branding replaces the old generic shell
- the sidebar exposes profile, memory, recommendation, workflow, and trust entry points
- the user can switch between Assistant, Mentor, and Companion modes
- the profile panel can be opened and edited

## Demo Flow

1. Open the homepage and point to the Persbot shell.
2. Show the sidebar and say the product now has visible module entry points.
3. Open the profile panel and fill in a research goal plus user preference.
4. Switch to Mentor mode and ask for project-start guidance.
5. Close by revisiting the module navigation and explaining that V1 is about product integration.

## Difference From Previous Version

- The old system looked like a generic chatbot backend.
- V1 turns it into a visible personalized product shell.
- The main proof is not deep intelligence yet, but a complete product surface for later iterations.
