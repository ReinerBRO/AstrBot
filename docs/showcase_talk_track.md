## Version Position

- Version theme: Mentor Loop
- Progress share: 18.75%
- Baseline for comparison: V2

## Whole-Group Upgrade Line

`Compared with V2, V3 now gives proactive guidance instead of only remembering and answering.`

## What Must Be Obvious On Screen

- a dedicated recommendation page is visible
- recommendation cards and a goal board are visible
- each recommendation can explain why it fits this user
- feedback actions such as useful, not useful, and refine are visible

## Demo Flow

1. Open the Recommendation page and point to the goal board.
2. Ask for weekly next steps for the personalized AI agent project.
3. Show the proactive recommendations instead of a passive answer.
4. Click one recommendation and show the explanation panel.
5. Click a feedback control and explain the mentor loop.

## Difference From Previous Version

- V2 could remember the user but still behaved mainly as a reactive assistant.
- V3 becomes a mentor that actively suggests next steps.
- The proof is a visible recommendation interface plus rationale and feedback controls.
