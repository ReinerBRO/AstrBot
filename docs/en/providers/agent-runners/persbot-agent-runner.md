# Built-in Agent Runner

By default, Persbot uses the built-in Agent Runner as the default executor. You don't need to configure anything to use Persbot's powerful built-in Agent Runner.

![image](https://files.persbot.app/docs/source/images/persbot-agent-runner/image.png)

With the built-in Agent Runner, you can use Persbot's [MCP Server](/use/mcp), [Knowledge Base](/use/knowledge-base), [Web Search](/use/websearch), and persona features.
